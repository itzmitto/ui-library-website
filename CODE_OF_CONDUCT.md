# Code of Conduct

## Our Pledge

We are committed to making participation in the UI Library Website project a welcoming, respectful, and inclusive experience for everyone.

All contributors, regardless of their experience or background, are welcome to participate.

## Expected Behavior

We encourage all community members to:

- Be respectful and considerate of others.
- Provide constructive feedback and accept criticism professionally.
- Welcome new contributors and help others learn.
- Respect different opinions, experiences, and perspectives.
- Focus on improving the project and maintaining a positive environment.

## Unacceptable Behavior

The following behavior is not tolerated:

- Harassment, discrimination, or personal attacks.
- Insulting or offensive comments directed at others.
- Trolling, intimidation, or deliberately disruptive behavior.
- Sharing someone's private information without permission.
- Any other conduct that creates an unsafe or hostile environment.

## Responsibilities

Project maintainers are responsible for clarifying and enforcing these standards.

They may edit, remove, or reject comments, issues, pull requests, or contributions that violate this Code of Conduct.

Repeated or serious violations may result in temporary or permanent restrictions from participating in the project.

## Reporting Violations

If you experience or witness unacceptable behavior, please contact the project maintainer privately through an available contact method on their GitHub profile.

All reports will be reviewed respectfully and handled as confidentially as reasonably possible.

## Scope

This Code of Conduct applies to all project spaces, including GitHub issues, pull requests, discussions, and other project-related communication.

## Commitment

Our goal is to build a friendly, collaborative, and professional environment where developers can share ideas, contribute code, and improve the UI Library Website together.
